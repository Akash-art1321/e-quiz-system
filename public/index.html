Frequently Asked Questions

Got Questions? We Have Answers.

How does the Anti-Cheating tab switch surveillance work? ▼
QuizNest monitors browser visibility and window focus events. If a candidate minimizes the exam window, opens another tab, or switches to an external application, the exam is instantly paused and locked. The examiner surveillance console records the timestamp, violation type, and photo evidence. Only an administrator can review and unblock the candidate's exam.
Can students see correct answers using browser developer tools? ▼
No, absolutely not. QuizNest uses strict server-side answer shielding. The examination delivery API completely strips the correct option index and explanations from the payload. Scoring and grading occur exclusively on the server after submission.
Can students change their personal or academic details? ▼
Details entered by the institution administrator (Full Name, Student ID, College, Roll Number, Course, Academic Year) are locked official records. Any attempt to modify these fields is rejected with HTTP 403 Forbidden. Students can only update emergency contact numbers and profile photos.
How does the single login portal work without role selectors? ▼
QuizNest provides a single, unified login screen. The backend automatically queries both admin and student records securely, creates an HTTPOnly signed session, and seamlessly directs the user to their designated dashboard.
